# Citing GalCraft

Please cite both the methods paper and the Astrophysics Source Code Library entry when using GalCraft for a publication:

- **Wang et al. (2024)**, *Validating full-spectrum fitting with a synthetic integral-field spectroscopic observation of the Milky Way*, MNRAS, 534, 1175–1204. [DOI: 10.1093/mnras/stae2148](https://doi.org/10.1093/mnras/stae2148).
- **Wang (2024)**, *GalCraft: Building integral-field spectrograph data cubes of the Milky Way*, Astrophysics Source Code Library, [ascl:2410.001](https://ascl.net/2410.001).

The full BibTeX records are provided in the [project README](https://github.com/purmortal/galcraft#citing-galcraft).
